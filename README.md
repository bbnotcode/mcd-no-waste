# 麦麦不白花

**把快过期的券和积分，变成符合你实际用餐计划的建议。**

麦当劳 MCP 创意开发大赛参赛项目初版，非麦当劳官方产品。

## 为什么做这个

“今日到期”可能是上午10:29结束；“卡包里有券”也不代表外送能用。麦麦不白花把这些信息放在一起，帮助用户决定先看哪张券、何时使用，以及是否需要特意消费。

适合已有麦当劳优惠券和积分、想减少遗漏又不想为了优惠多花钱的用户。

## 能做什么

- 按精确截止时间整理今天、未来3天及以后到期的券，保留早餐时段与渠道限制。
- 查询本月与下月将过期的积分，区分已经失效的积分。
- 根据用餐计划和预算解释“优先考虑、可以等等、不必特意消费”。
- 选定门店后进一步核验适用券及官方核价，无法核验时明确提示。
- 默认只读，不自动领券、兑换、抽奖或下单。

## 安装

本项目由一个 Agent Skill 与一个可独立运行的 Python 分析器组成，不需要网页服务器或常驻进程。

1. 在支持 Agent Skills 的 AI 客户端中，导入 [`skills/mcd-no-waste`](skills/mcd-no-waste)。也可将其中 `SKILL.md` 作为当前任务指令加载，并保留随附脚本。不同客户端的导入方式以各自文档为准。
2. 在麦当劳官方 MCP 平台申请个人 Token，连接 `https://mcp.mcd.cn`。[`mcp-config.example.json`](mcp-config.example.json) 是通用示意，不是所有客户端可直接导入的配置。用客户端的环境变量或安全凭证功能设置 `MCD_MCP_TOKEN`；不支持变量插值的客户端请在其私有设置中填写，不要提交到仓库。
3. 在对话中说：“帮我看看哪些麦当劳券和积分快过期了，先别替我领券或下单。”

Skill 通过客户端已连接的 MCP 执行实时查询；Python 分析器只处理已取得的 JSON，不直接联网。

## 试用示例

```text
帮我整理麦当劳快过期的券和积分。
我周末才打算吃，预算25元，到店自取；哪些可以等，哪些不用特意消费？
```

助手先取得真实卡包和积分数据，再结合计划提出建议。如果用户选择具体券，会继续核验门店与点餐渠道，避免把卡包权益当成可用订单优惠。

无需账号也能运行合成数据演示（Python 3.9+）：

```sh
python3 skills/mcd-no-waste/scripts/analyze.py --now '2026-10-16T11:00:00+08:00' < examples/synthetic.json
python3 -m unittest discover -s tests -v
```

演示里，一张早餐券在10:29:59结束，11点查询会归入“已到期”；另一张券仅提供日期，会保留“日级截止，需查看详情”的不确定性。示例全部虚构，不能用于点餐。
